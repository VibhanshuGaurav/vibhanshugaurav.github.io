# vibhanshu-gaurav.github.io

Personal portfolio website for Vibhanshu Gaurav.

## Files
- `index.html` — the whole website (styles, scripts, photo, background, CV, and map are all built into this one file)
- `assets/photo.jpg` — profile photo (also uploaded separately so link-preview cards on WhatsApp/LinkedIn can show it)
- `assets/cv.pdf` — a plain copy of the CV (not required by the site, kept as a backup/direct-download option)

## How to publish
1. Create a public repo named exactly `yourusername.github.io`
2. Upload `index.html` and the `assets` folder together
3. Settings → Pages → Source = `main` branch → Save
4. Visit `https://yourusername.github.io` after a minute

## How to update later
Because everything is embedded in `index.html`, updating the photo, CV, or background photo means asking for a rebuilt `index.html` rather than swapping a file in `assets`. The `assets` folder is only used for the link-preview image and as a backup CV copy.
