# vibhanshu-gaurav.github.io

Personal portfolio website for Vibhanshu Gaurav.

## Files
- `index.html` — the whole website (styles and scripts are inside it)
- `assets/photo.jpg` — profile photo
- `assets/cv.pdf` — downloadable CV (linked by the "Download CV" button)

## How to update later
1. Open this repository on github.com
2. To change text: click `index.html` -> pencil (Edit) icon -> make changes -> Commit changes
3. To replace the CV or photo: open the `assets` folder -> Add file -> Upload files -> upload a file with the SAME name (`cv.pdf` or `photo.jpg`) to overwrite -> Commit changes
4. The live site refreshes in about a minute (hard-refresh your browser if you still see the old version)
